# 搜索数据分析与运营看板 · 公开演示

将搜索指标、质量评估、问题治理与需求进展组织为可交互的周报。

[在线体验](https://oo1007.github.io/search-analytics-demo/) · [作品集主页](https://github.com/oo1007)

## 体验内容

- 数据概览：指标卡片、类目图表与可展开明细。
- 评估和业务：质检、问题归类与需求跟踪。
- 女性专项：专项指标、实验记录与进度。
- 历史周报：保留原有周期选择与页面切换。

## 我的工作与设计思考

独立整理信息结构并实现页面，把“看指标—定位问题—跟踪行动”串联在一个入口中。通过概览与明细分层，兼顾快速阅读和问题追查；通过周期归档，保留复盘线索。

## 数据说明

这是求职作品展示副本。业务数字已在发布源文件中替换或移除，页面继续遮蔽数字；内部资料链接已移除。演示数值、比例和图形不代表真实业务结果，也不用于评价实验成效。

原始业务仓库与本仓库分开管理。本仓库不包含原始提交历史。

## 本地运行

使用任意静态网站服务器打开本目录，例如 `python -m http.server 8000`，再访问本机对应端口。无需业务账号或模型密钥。

本目录包含发布页面与静态资源，不是原始前端开发工程。
